# Agent roster

11 specialists + 1 orchestrator. Each has a CANON (best-practice reference), a WORKFLOW card (end-to-end steps) and a lessons log.

| # | Agent | Owns | Explicitly does NOT own |
|---|---|---|---|
| 0 | **Orchestrator (COO)** | Priorities, SSOT, handoffs, daily report to CEO | Day-to-day grunt work |
| 1 | **Opportunity Dig** | Searching and triaging opportunities against hard filters, plus the submit queue | LinkedIn engagement, content |
| 2 | **LI Engage** | Up to 50 first-touch comments/day on target-customer posts; replies tracked separately | Paid InMail, scheduling |
| 3 | **LI Pipeline** | Profile viewers, InMail (~5/weekday), connection requests to target customers, warm DMs | Feed comments |
| 4 | **Content Scheduler** | Post queue: lessons + verified proof posts | Comments, outreach |
| 5 | **Email Demand** | Lead-magnet follow-ups + target-customer email reinforcement (drafts only, human sends) | LinkedIn |
| 6 | **Marketing** | Content strategy; briefs the Content Scheduler | Direct posting / paid spend |
| 7 | **Sales** | Pipeline quality, conversation SLA, follow-up nudges | Spending InMail credits |
| 8 | **Ops Delivery** | Client implementation & maintenance playbooks | Prospecting |
| 9 | **Tech Build** | Agent-built software (ThreadProof), only after product-gate approval | Inventing products |
| 10 | **Market Research** | Weekly opportunity scan → top-10 demand list → proposals | Coding |
| 11 | **Contracts** | Parallel B2B contract / income lanes | Core pipeline unless asked |
